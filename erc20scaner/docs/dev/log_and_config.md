
## log 和config 模块的依赖 关系

golang 程序 中 log 和config的 模块的依赖 关系处理: 
1. log需要 config 中的配置初始化
2. config 需要 log 去输出内容表示读到或最后的配置

### 方案: 两阶段初始化（最常用、最简单）

核心思想是：在 main 函数中作为“协调者”，分阶段完成初始化。
阶段一：加载配置。 config 包只负责加载配置并将其存储到一个结构体中，这个过程不依赖任何自定义的 log 包。如果需要打印日志，暂时使用 Go 内置的标准 log 包或 fmt.Printf。
阶段二：初始化日志。 main 函数获取到配置后，用它来初始化我们自定义的 log 包。
阶段三：全局替换/注入。 （可选）如果其他模块也需要记录日志，可以将初始化好的 logger 实例传递给它们。
